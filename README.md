# Han Launcher

 Han Launcher — Windows uygulamalarını tek bir yerde toplamak ve hızlıca başlatmak için geliştirilmiş modern bir launcher.

##  Özellikler

- 🚀 Uygulamaları hızlı başlatma
- ⌨️ Klavye ile kontrol
- 🖱️ Tek tıklamayla uygulama açma
- 👤 Kişisel hesap ID'si
- 🎨 Tema seçenekleri
- 🖥️ Modern Windows arayüzü
